GALERIE — MVP
================

Protótipo demonstrativo em HTML, CSS e JavaScript puro.

Como abrir:
1. Extraia a pasta.
2. Abra o arquivo index.html no navegador.
3. Clique em "Entrar na demonstração".

Funcionalidades do MVP:
- Login demonstrativo
- Feed vertical
- Publicação com imagem
- Publicação de obra à venda
- Curtidas e salvamento simulados
- Mercado de obras
- Página de detalhes da obra
- Explorar
- Planos de impulsionamento
- Notificações
- Chat local demonstrativo
- Salvos
- Perfil do artista
- Tema claro/escuro
- Layout responsivo

Observação:
As imagens, fontes e ícones usam serviços online (Unsplash, Google Fonts e Font Awesome).
Não há backend, banco de dados ou autenticação real.
